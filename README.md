# 💻 C / C++ Practice

Basic C and C++ programs I wrote while learning.

| File | What it does |
|---|---|
| `c/prime.c` | Checks if a number is prime |
| `c/factorial.c` | Factorial using recursion |
| `cpp/student_grades.cpp` | Average and grade for marks |
| `cpp/reverse_string.cpp` | Reverses a string |

Compile with `gcc file.c -o out` or `g++ file.cpp -o out`.
